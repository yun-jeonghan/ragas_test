date: 2026-05-29 scope: 1 PDF queries: local + global metrics: context_precision, faithfulness

요약

이 보고서는 sample.pdf를 GraphRAG에 인덱싱한 뒤, local/global 질의를 실행하고 그 GraphRAG 검색 결과를 Ragas로 평가한 smoke test 결과를 정리한 것이다.

결론적으로, 평가 대상은 일반 텍스트가 아니라 GraphRAG가 반환한 검색 결과와 답변이었다.

실행 범위

  • 입력 문서: /tmp/graphrag-smoke/input/sample.pdf
  • GraphRAG workspace: /tmp/graphrag-smoke/workspace
  • local query: Where does Bob work?
  • global query: Summarize the workplace relationships described in the document.
  • 평가 파일: /tmp/graphrag-smoke/eval_quick.json

해석

  • 이 smoke test는 GraphRAG 인덱스가 제대로 생성되고, local/global 검색이 문서 사실을 회수하는지 검증했다.
  • 평가는 해당 GraphRAG 검색 결과를 사용했기 때문에, 단순 LLM 답변이 아니라 검색 품질까지 포함한 결과다.
  • 점수는 매우 높았지만, 샘플이 1개 PDF / 2개 질의뿐이라 통계적 의미는 제한적이다.
  • global query는 thinking 출력 때문에 JSON 파싱 문제가 있었고, enable_thinking=false 프록시로 우회한 뒤 정상 평가했다.
